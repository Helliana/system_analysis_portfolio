# 1. Контекст

Программный продукт представляет собой мобильное приложение, предоставляющее пациенту возможность самостоятельно взаимодействовать с системой записи на приём.

# 2. Scope MVP

## Что входит

* просмотр списка медицинских специализаций;
* поиск и просмотр врачей;
* просмотр расписания врачей;
* запись на приём;
* просмотр предстоящих записей;
* перенос записи;
* отмену записи;
* получение уведомлений;
* просмотр истории посещений.

## Будущие нововведения

* Авторизация и регистрация через аккаунт Госуслуг, Yandex, VK.
* Авторизация с помощью отпечатка пальцев
* Проверка документов врача
* Рейтинги и отзывы врача
* Медкарта - загрузка результатов приема, анализов, данных из Госуслуг
* Трекер менструального цикла
* Промокоды/скидки
* Возможность записи члена семьи (не хозяина аккаунта а его родственника/друга)
* Статистика по посещениям, отзывам
* Онлайн-оплата
* Удаление аккаунта

# 3. Моя работа

* анализ требований;
* декомпозиция функциональности;
* подготовка SRS;
* моделирование сценариев;
* описание API;
* проектирование модели данных;
* подготовка интеграционного взаимодействия.

# 4. Подход к работе с требованиями

1. Сбор информации
  * интервью с заказчиком/пользователями;
  * анализ существующего процесса;
  * анализ ограничений и документации.

2. Анализ
  * AS IS / TO BE;
  * выявление проблем и альтернативных сценариев;
  * определение функциональных и нефункциональных требований.

3. Формализация
  * User Stories / Use Cases;
  * BPMN;
  * UML;
  * прототипы;
  * SRS;
  * API-контракты.

4. Верификация
  * полнота;
  * непротиворечивость;
  * однозначность;
  * проверяемость;
  * трассируемость требований к тестам.
