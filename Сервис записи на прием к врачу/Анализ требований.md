# Анализ требований

Данный документ содержит описание процесса сбора и анализа требований.

# Источники требований

* интервью с заказчиком;
* интервью/обсуждение с пользователями;
* анализ текущего процесса;
* анализ существующей документации;
* выявление ограничений.

# Анализ

* Процесс работы "AS IS";
* проблемные места;
* Процесс работы "TO BE";
* альтернативные сценарии.

# Формализация

* User Story;
* Use Case;
* BPMN;
* прототипы Figma;
* SRS.

# Верификация

* полнота;
* непротиворечивость;
* однозначность;
* проверяемость;
* трассируемость.
